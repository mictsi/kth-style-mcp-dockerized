Themes

The server reports 5 theme contexts. Each panel below opts into one of them, so the identical markup can be compared across all of them at once.

  • theme-default
  • theme-student-web
  • theme-intranet
  • theme-inverse
  • theme-dense

theme-default

The public web theme. The package reset applies it to :root, so it is what you get for free.
